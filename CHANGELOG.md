# Changelog

All notable changes to this project will be documented in this file.

## 1.0.0 - 2026-08-16

- Parse and validate RFC 9116 `security.txt` fields with structured errors, recommendations, notifications, and registered-field accessors.
- Serialize typed options to canonical LF-terminated documents with validated URIs, RFC 3339 expiry values, and RFC 5646 language tags.
- Support CSAF provider-metadata fields and syntactically complete OpenPGP cleartext envelopes.
- Ship zero-dependency ESM and CommonJS builds with TypeScript declarations and browser compatibility.
- Support Node.js 18 and newer.
